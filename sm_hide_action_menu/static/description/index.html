Hide Action Menu

Control Action menu visibility per user. Hide all actions globally or only for selected Odoo models.

Per User Rules

Configure which users should lose access to the Action menu from the standard user form.

Specific Models

Apply hiding only on selected models such as sale orders, invoices, products, contacts, or custom models.

List and Form Views

The rule works on both list and form controllers in the Odoo backend.

Action Menu Control

Clean backend views for users who should not access bulk actions.

Hide Action Menu Access Right

Administrators enable Hide All Action Menu from the user Access Rights tab. Specific models can also be selected when the rule should only apply to selected Odoo models.

List View Action Menu Hidden

After the hide rule is enabled, users can select multiple records but the Action menu entries are removed from the list view.

Form View Action Menu Hidden

The same access rule also works inside form views, so restricted users cannot use hidden Action menu operations on a single record.
